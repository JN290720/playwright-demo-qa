# 判断の記録（決まったこと・その理由）

このプロジェクトで決まったことを、日付・判断・理由・関連 Issue/PR の順に 1 行ずつ残す。「なぜそうしているか」を、後から辿るための文書。

- 書き方: 判断の根拠は、Issue・PR・コードで確認できたものだけを書く。確認できないものは「要確認」と書く
- 状態: **決定**（実装・文書に反映済み）／ **承認待ち**（PR やユーザーの判断が未了）／ **要確認**（記録と現状が一致するか未確認、または見直し中）
- 判断の出どころは、ユーザーのコメント（Issue #155 など）と、関連 Issue。エージェント・リーダーの発言だけでは、判断として記録しない。`[ユーザー]` の接頭辞が決まる前（2026-10-20 より前）のユーザーのコメントには、接頭辞が無いものがある（その場合は、コメント番号で示す）
