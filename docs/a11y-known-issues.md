# アクセシビリティ（a11y）の既知の不備の台帳

テスト対象のデモサイト（SauceDemo）自体の不備のうち、**テストで除外している・失敗を期待している**ものを、理由と確認日つきで記録する。
サイトが直ったときに、気づけるようにするため（除外のままにすると、直ったことも、再発も見逃すため）。

- **a11y** = accessibility（アクセシビリティ）。障害のある人や高齢の人でも、Web サイトを使えるかどうか
- **axe** = a11y の自動検査ツール。**WCAG** = a11y の国際的な基準（WCAG 2.1 の Level A / AA を使っている）

## 運用
- **除外・失敗を期待するテストを増やすときは、この表に追記する**（理由と確認日つき・テスト名）
- `test.fail()` の追加・削除と、この表の行の追加・削除は、**同じ PR で行う**（片方だけを変えると、台帳とテストが食い違う）
- `test.fail()` のテストが**予期せず成功した**場合は、サイトが直っている。そのテストを通常のテストに戻し（`test.fail()` を削除）、この表から消す
- 定期的に（数か月に 1 回）、各項目が今も再現するか確認する
