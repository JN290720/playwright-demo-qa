# アクセシビリティ（a11y）の既知の不備の台帳

テスト対象のデモサイト（SauceDemo）自体の不備のうち、**テストで除外している・失敗を期待している**ものを、理由と確認日つきで記録する。
サイトが直ったときに、気づけるようにするため（除外のままにすると、直ったことも、再発も見逃すため）。

- **a11y** = accessibility（アクセシビリティ）。障害のある人や高齢の人でも、Web サイトを使えるかどうか
- **axe** = a11y の自動検査ツール。**WCAG** = a11y の国際的な基準（WCAG 2.1 の Level A / AA を使っている）

| # | 内容 | テストでの扱い | 確認日 | 基準 |
|---|---|---|---|---|
| 1 | 商品一覧の並び替えのドロップダウン（`select`）に、ラベルが無い | `saucedemo-accessibility.spec.ts` の P2 で、axe のルール `select-name` を**除外** | 2026-10-19 | WCAG 4.1.2 / 1.3.1 |
| 2 | カートのリンクが、`href` の無い要素（`role="button"`）で、**Tab の移動順に入らず、Enter でも開けない**（キーボードだけでは、カートを開けない） | K3b で **`test.fail()`（失敗を期待）**。K4 の購入フローは、カートを開く操作だけマウスで行う | 2026-10-20 | WCAG 2.1.1（キーボード） |
| 3 | 購入手続きの入力欄（郵便番号）で Enter を押しても、フォームが送信されない（「Continue」ボタンの操作が必要） | 失敗を期待するテストにはせず、K4 で「Continue」ボタンに移動して Enter する形にした | 2026-10-20 | （参考。WCAG の必須ではない） |

## 運用
- **除外・失敗を期待するテストを増やすときは、この表に追記する**（理由と確認日つき）
- `test.fail()` のテストが**予期せず成功した**場合は、サイトが直っている。そのテストを通常のテストに戻し（`test.fail()` を削除）、この表から消す
- 定期的に（数か月に 1 回）、各項目が今も再現するか確認する
